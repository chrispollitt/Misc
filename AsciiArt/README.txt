There are a few tools that can display an ASCII art version of your Linux distribution's logo in the terminal:

Neofetch – A popular command-line system information tool that displays your OS logo in ASCII art alongside system details.

Screenfetch – Another tool that automatically detects your Linux distribution and shows an ASCII version of the logo with system information.

Linux_Logo – A utility that prints a color ANSI version of the Linux distribution logo along with system details.

Each of these tools has its own unique features, but they all serve the purpose of showcasing your distro's logo in a stylish way.
